# 종합도매 매출 · MBO 예측 대시보드

## 배포
1. ZIP 압축을 해제합니다.
2. 폴더 안의 `index.html`, `styles.css`, `app.js`, `data.js`를 GitHub 저장소 루트에 업로드합니다.
3. GitHub Settings → Pages → Deploy from a branch → `main / root`로 설정합니다.
4. 생성된 GitHub Pages 주소로 접속합니다.

## 초기 데이터
- `종합도매 마감.xlsx`: 2026년 4~7월 업체/전체 매출 추이의 초기 기준값
- `260821_월별.xlsx`: 2026년 8월 21일 기준 월 누계 상세
- `260821_일자별.xlsx`: 2026년 8월 일자별 상세
- 2026년 8월 MBO 기본값: 269.4억 (첨부 마감파일 기준)
- MBO 목표는 **기준월별로 별도 저장**되며 화면에서 수정 가능합니다.

## 월별 업데이트 방법
- **월별 EXPORT 업데이트**: 첫 열/컬럼에 `년월`이 있는 EXPORT 파일을 선택합니다.
- **일자별 EXPORT 업데이트**: `일자` 컬럼이 있는 EXPORT 파일을 선택합니다.
- 같은 월 파일을 다시 올리면 그 월 상세 데이터는 새 파일 기준으로 교체됩니다.
- 여러 월 파일을 한 번에 선택할 수 있습니다.

## 담당자 규칙
- 백제약품 원주 / 영남 → 임인숙
- 유진약품 / 아이팜코리아 → 정직한
- 그 외 → 배영훈

담당자를 먼저 선택하면 업체 선택 목록도 해당 담당자 업체로 자동 제한됩니다.

## 예측 로직
- 예상 마감 = 현재 누계 ÷ 기준일 기대 진행률
- 기준일 필요 누계 = 해당 월 MBO × 기준일 기대 진행률
- 당일 필요 매출 = 당일 필요 누계 - 전 영업일 필요 누계
- 순도 = 현재 누계 ÷ 기준일 필요 누계
- 업체별 MBO = 전월 업체 매출 비중으로 전체 MBO 배분
- 과거 일자별 EXPORT가 2개 월 이상 누적되면 `1차 발행 전 / 1~2차 사이 / 2차 발행 후` 구간을 맞춘 뒤 동일 구간 내 영업일 위치의 누계율 평균을 기대 진행률로 사용합니다.
- 주말, 공휴일, 대체공휴일 및 화면에서 입력한 추가 휴무일은 영업일에서 제외합니다.
- 이력이 부족하면 공휴일을 제외한 영업일 경과율을 사용합니다.

## 데이터 보관
- 업로드한 결과는 브라우저 IndexedDB에 저장됩니다.
- 서버로 파일을 전송하지 않습니다.
- 브라우저 초기화/PC 교체에 대비해 `JSON 백업`을 주기적으로 내려받는 것을 권장합니다.

## 외부 라이브러리
- SheetJS: Excel 파일 브라우저 분석
- Chart.js: 차트 렌더링

현재 버전은 GitHub Pages에서 CDN을 통해 위 라이브러리를 불러옵니다. 인터넷 차단 환경에서는 Excel 업로드/차트 기능이 제한될 수 있습니다.
