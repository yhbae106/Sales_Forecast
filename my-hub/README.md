# MY HUB · 나의 업무 관리

GitHub Pages 주소: https://yhbae106.github.io/Sales_Forecast/my-hub/

- 매출 예측·마감 관리, SLA·DCM 관리, 기고 수금내역서 연결
- 업무 추가/수정/삭제, 검색, 분류, 즐겨찾기, 최근 방문
- 직접 입력하는 진행 상태, 마감일, 메모
- JSON 백업 및 다른 PC에서 복원 (같은 ID 또는 URL의 업무 내용 갱신 · 복원 전 확인)

## 저장 방식
기본 목록은 `catalog.json`에서 관리합니다. 개인 변경 내용은 브라우저 localStorage에 저장되며 GitHub에 자동 게시되지 않습니다. 기기 변경 전 백업 후 복원하세요. 이전 ChatGPT Sites 버전의 계정 데이터와는 별도입니다. 브라우저 데이터 삭제 시 개인 변경 내용이 사라질 수 있습니다. 비밀값을 소스나 catalog에 넣지 마세요.

## 개발
`npm install` 후 `npm run build`. 생성한 `hub.js`와 수정한 소스를 함께 커밋합니다. `npm test`로 저장/복원 동작을 검증하고 `npm run verify`로 소스와 번들의 일치 여부까지 검증합니다. 루트의 기존 GitHub Pages 배포 워크플로가 이 폴더도 배포합니다. 별도 Node 서버나 외부 JS CDN이 필요하지 않습니다.

기존 업무 사이트의 데이터·권한·계산식은 변경하지 않습니다. iframe이 차단되거나 로그인이 필요하면 새 탭 열기를 사용합니다.

## 2026-10-30 안정성 개선
- 복원 시 기존 업무의 메모·상태·마감일·즐겨찾기까지 갱신하고, 백업에 없는 업무는 유지합니다.
- 복원은 한 번의 저장으로 반영합니다. 용량 초과나 잘못된 파일이면 기존 데이터가 유지됩니다.
- 기존 v1 브라우저 기록은 v2로 자동 이관합니다. 다른 탭의 오래된 수정은 거절하고, Web Locks 지원 브라우저에서는 탭 간 쓰기를 순차 처리합니다.
- 공통 목록 및 백업의 URL·실제 날짜·숫자·중복을 검증합니다.
- 기존 저장소 회귀 하네스가 MY HUB 검사도 실행하므로 실패한 버전은 정상 배포 경로의 검증 단계를 통과하지 못합니다.
- `build-meta.json`은 빌드 시 생성됩니다. 소스만 고친 뒤 번들 재생성을 빠뜨리면 자동 검증이 실패합니다.
